### 2.1 ⚠️ 计价口径（这条会直接决定费用算得对不对）

**生效凭证来自 `~/.everything-rag/config.json`，不是 `backend/.env`。**
依据：`settings_store.py:3` 的优先级 `config.json > env/.env > 默认值`，且运行路径走 `create_chat_model_from_config(get_settings_store().load().chat)`。

| 用途 | **生效值（config.json）** | `.env`（仅缺省回退） |
|---|---|---|
| Chat | `https://api.deepseek.com` / **`deepseek-flash`** | `https://opencode.ai/zen/go/v1` / `deepseek-v4-flash` |
| Embed | `https://api.siliconflow.cn/v1` / `Qwen/Qwen3-Embedding-8B` | 同左（key 不同） |
| Vision | SiliconFlow `Qwen/Qwen3-VL-32B-Instruct` | — |

⇒ **费用必须按 `api.deepseek.com` + `deepseek-flash` 计价**；按 `.env` 的端点/模型会算错。

## 3. 三档方案（建议从 A 档开始）

### A 档｜最小真实冒烟（建议先做）
- A01 一次真实新闻检索（1 次 Tavily 搜索 + 1–2 次网页读取）
- A18 四档各 1 题（4 次对话请求）
- A19 一次多轮工具调用（2–4 次对话请求）
- **预计**：约 10 次模型请求 + 约 3 次搜索请求。量级：几分钟、费用可忽略。
- **产出**：证明真实链路能通，报告可标 A01/A18/A19「已执行 + 证据」。

### B 档｜PRD 规定的完整评测
- 路由评测：≥120 题（PRD 16.3）
- 答案质量：≥40 题 × 2 个版本（基础版 vs V1.2.0），覆盖内部方案/数值条件/多子问题/历史讨论/新闻/来源冲突
- 思考强度：≥20 题 × 4 档 × 每题 ≥3 次（PRD 16.4）≈ **240 次以上对话请求**
- **预计**：数百次模型请求 + 数十次搜索请求，**小时级耗时与可感知费用**。
- **产出**：PRD 16.3/16.4 的全部发布指标实测值。

### C 档｜A26 真实数据迁移
- 对象是 `~/.everything-rag/`（**241 MB 向量库 + 873 KB 真实会话历史 + 22 MB 图片库**）。
- **硬前提**：先完整备份（PRD 15.2 第 1 步），且迁移期间无写入进程。
- 迁移本身要求**零远程模型调用**（可用出网审计断言，不需要花模型费用）。
- **风险**：迁移失败可能影响你正在使用的真实知识库。**建议在备份后、且你方便回滚的时间窗执行。**

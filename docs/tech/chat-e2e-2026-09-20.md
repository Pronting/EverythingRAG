# 对话端到端验证

测试页面：`http://127.0.0.1:9999/`。浏览器通过真实点击调用当前后端、模型服务和本地知识库。测试使用独立浏览器会话，消息保存于当前工作区。

## 当前行为

- 答案保存后，SSE 订阅接收答案和完成事件；连接恢复时补读事件。
- 模型调用在后台执行，服务继续处理设置修改、停止和会话读取。
- 生成期间可以调整权限与思考等级。思考等级从下一次模型调用生效，已经发出的请求继续使用原设置。
- 会话历史保存消息、任务关联和引用，刷新后恢复当前任务或结束状态。
- 连续追问包含最近历史；编辑重发等待历史截断成功后更新页面。
- 本地文档和明确联网请求进入相应查询流程。引用要求与对应问题共同处理。
- 研究阶段按资料缺口补充检索，准备好资料后生成答案并直接发布。
- 引用编号、来源身份和工作区归属由程序检查，答案保存实际资料缺口。
- 等待区域显示当前阶段，审批卡片支持刷新恢复和切换会话。

## 验证结果

2026-09-20，六组功能测试通过。深度思考的本地文档问答测试耗时约 1.2 分钟，引用详情及刷新恢复通过。事件记录确认答案只生成一次，生成后没有工具查询。

额外的记忆系统问题耗时测试未通过 90 秒要求。该问题被分配给两个 General 任务，模型调用在 120 秒超时，尚未进入答案生成阶段。任务编号为 `run-9d5dd3d616b24232af30a8c610c284dc`。

26 项后端回归使用真实 SQLite、实际答案处理函数和 LangGraph 编译，全部通过。前端 TypeScript 与 Vite 构建通过，修改涉及的 Python 文件通过 Ruff 检查。测试调用当前配置的模型服务，回答耗时随模型和检索过程变化。

## 执行命令

在 `frontend` 目录执行：

```powershell
npx playwright test -c playwright.live.config.ts
npm run build
```

在 `backend` 目录执行：

```powershell
.venv/Scripts/python -m unittest discover -s live_tests -v
.venv/Scripts/python -m unittest tests.test_verification tests.test_answer_artifact -v
```

后端回归覆盖真实 SQLite 保存、事件订阅、答案发布、编辑限制、设置保存、路由、历史上下文、引用编号和主流程编译。
